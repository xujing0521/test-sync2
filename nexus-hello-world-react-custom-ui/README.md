# nexus-hello-world-react-custom-ui — Hello World

A one-page hello world. Demonstrates Nexus [Custom UI](https://developer.pingcode.com/guide/development/custom-ui-with-react) with React. Extension entry: [Project — Component page](https://developer.pingcode.com/reference/resource/extensions/pjm-project-page).

## Prerequisites

Environment, account, and CLI setup: [Getting started](https://developer.pingcode.com/guide/started/setup).

## Quick start

See [CLI](https://developer.pingcode.com/reference/cli/overview).

```bash
nexus register <app-name>   # first time only
npm install
npm run deploy
nexus distribute -s <your-domain>.pingcode.com -e development
```

Then install from enterprise admin **App review** and open **Hello World** on a project's component page (route `hello-world`).

Related commands: [deploy](https://developer.pingcode.com/reference/cli/deploy), [distribute](https://developer.pingcode.com/reference/cli/distribute), [serve](https://developer.pingcode.com/reference/cli/serve).
