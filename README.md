# Nexus Example Apps

Example apps for [Nexus](https://developer.pingcode.com/). This repository collects focused demos you can deploy and try in PingCode.

| **nexus-event-feed** | [`nexus-event-feed`](./nexus-event-feed) | Lifecycle, system, scheduled, webhook, and app events on one timeline, on [Global — App hub](https://developer.pingcode.com/reference/resource/extensions/global-app-hub) |
